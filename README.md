# 音乐工具箱 Ultra

当前交付版：`v13.5.13`，构建 `2026.09.17.1`（需按清单完成真机验收）  
开发者：黄鸡（BY 黄鸡）

本目录是同一套最终代码生成的两个交付形态：

- `index.html` 与配套文件：GitHub Pages / PWA 正式版。
- `Music-Toolbox-Ultra-v13.5.13-Standalone.html`：手机本地直接打开的单文件版，用于快速检查；不提供 Service Worker 自动更新。

目录中不包含任何旧测试版文件。

## GitHub Actions 发布

1. 解压最终压缩包。
2. 把最外层项目目录里的全部内容上传到 GitHub 仓库根目录，包括隐藏目录 `.github`。
3. 在 GitHub 仓库中打开 `Settings → Pages`，将 `Source` 设为 `GitHub Actions`。
4. 向 `main` 或 `master` 分支提交后，工作流会安装锁定的 QA 依赖，运行完整 QA，并校验全部离线素材的文件大小和 SHA-256，再整体发布。
5. Actions 页面显示绿色成功后，再刷新正式网址。

仓库名和 Pages 子路径可以改变。所有站内资源均使用相对路径，不依赖固定的 GitHub 用户名或固定项目名称。

## 离线与更新机制

- 第一次从 HTTPS 正式网址进入时，PWA 会把页面、脚本、样式、96 个正式节拍器／鼓组音源、制音、图标、视唱曲库及赞助/联系图片完整缓存到设备。
- 新版本必须先把资源清单里的全部文件下载并校验成功，才会替换旧缓存。某个文件缺失时只删除本次临时缓存，保留设备里的完整旧版。
- 进入页的“检查失败”会显示具体缺失路径；不会阻止使用当前完整版本。
- 进入页可按浏览器能力一键“添加到桌面”；iPhone 等不支持一键安装的平台会显示操作指引。
- 进入页“重置缓存”先验证在线版本，再注销当前应用路径的 Service Worker、删除该路径的工具箱缓存及已知工具箱本地设置和自定义数据，并重新联网载入。不会清空其他网站应用的全部同源存储；同域工具箱副本目前共用设置，确认框会明确提醒。浏览器 HTTP 缓存和系统权限不能由网页全部擦除。
- 直接打开本地单文件不会检查云端更新；正式 PWA 才会跟随已部署网页更新。

## iPhone 与麦克风

应用启动时只初始化媒体播放，不会预先占用麦克风。进入调音器或开始录音时才申请麦克风，离开后释放并尝试恢复播放路由。默认“自动（推荐）”，根据系统类别选择原声或 iPhone 延音配置；仍可手动选择“标准原声、iPhone 延音增强、系统语音增强”。iOS 浏览器在麦克风开启期间可能仍由系统显示录音音量界面，这是 Safari / WebKit 的系统行为。

## 发布前本地校验

需要 Node.js 18 或更高版本：

```bash
npm ci --ignore-scripts
node tools/build_standalone.mjs
node tools/build_release.mjs
node tools/build_release.mjs --check
node tools/qa_final.mjs
```

全部通过后，`release-assets.json` 才与当前项目一致。以后改动任何正式资源，都必须重新运行上述构建与校验。

### 13.5.9

- 调音器增加 A0–C8 的 88 半音等距音域条；蓝点是各弦目标，指针是检测音，显示音名、八度、最接近或锁定弦及偏差。它是音高示意，不是琴弦张力传感器。
- 检测方式支持自动、原有 YIN + HPS、宽音域 YIN。自动模式只在持续有输入、原算法失效且后备算法连续有效时回退；静音不触发切换。可手动恢复原算法或切换麦克风采集模式。
- 设备信息仅推断系统和类别，不保证具体型号；仍使用浏览器 Web Audio / getUserMedia，不承诺存在可随意切换的多个底层音频驱动。

- 桌面调音器使用内部双栏，手机纵向可滚动；提高关键控件可读性，保留蓝色主色、深浅色和安全区。
