- 88 键音域目标音名改为紧凑气泡标签：避让行距由 22px 收紧为 18px，标签带边框、半透明背景和指向蓝点的小尖角；目标音高位置、蓝点、指针和琴键试听坐标保持不变。
- 琴头采用主题跟随的极简线稿：标准 3+3 弦钮顺序为左 4/5/6、右 3/2/1，移除琴头内部署名；轮廓改为适度加宽的弧肩窄腰，弦轴靠近两侧，外侧旋钮柄清晰伸出，三行弦钮与六根弦严格对齐并连到底端。
- 调音器识别与显示独立限频：默认每 0.1 秒取一次新音高结果，并用 0.25 秒稳定确认窗口抑制跳变；诊断设置可选 0.1／0.25／0.5 秒，仅影响调音器。主表盘和 88 键横轨保持独立平滑过渡。
- 调音器 88 键上方增加独立音高横轨，目标音名、蓝点和实时指针共用琴键坐标；同音弦合并标注。保留 88 键试听与六弦选择，移除展开大琴键和重复说明。变调夹高亮摘要可展开详情。
- 普通节拍器默认“重拍区别 · 多音色”，第一拍使用重拍音色，普通拍使用普通拍音色，强弱同时由力度体现；“同音色 · 力度计拍”仍可手动选择。“鼓组配器 · 多音色”保留 T06 的首拍 Kick、第三拍 Clap、二四拍与细分 Hi-hat。
- T06 默认底鼓改用约 136 ms 的干脆短音，主体约 155 Hz，快速衰减音高尾音；用户确认的 T04–T06 镲片字节不变。新增干脆 Trap、硬击 Trap、颗粒 Breakbeat 三套共 24 个原创 CC0 鼓音，正式音源共 120 个。
- WAV 峰值标准化至 PCM16 满幅，播放保留音源平衡和混音余量。峰值一致不等于主观完全等响；短底鼓仍有频率成分，不宣称物理上完全无音高。
- 节奏编排首先选择鼓组音色；推荐风格随鼓组置前，其余风格仍可选。28 种风格各有 8 个实际不同的节奏变体，支持换个节奏、自动／手动力度、连音、锁轨和撤销。风格是参考骨架，不代表穷尽全部流派。
- 编排网格优先占据页面，拍号、网格、力度、Swing、保存和旧四轨入口移入“设置／保存”。小屏按轨道与时间分页，不缩小鼓点；“展开”可用浏览器全屏，支持时尝试锁横屏，iPhone 请手动转动。
- 练耳保留单音、音程、三和弦、七和弦，增加和弦综合及和弦进行：28 种可勾选性质、64 个独立模板，支持随机／指定调、调式、进行，以及副属和弦、调式借用开关。无法匹配时明确提示，不忽略筛选。
- 音程提供旋律（先后）和和声（同时）两种听法。全部六类训练共用“播放参考调式”；关闭后直接听题，不播放前置音阶或 La 定音。设置在本机记忆，切换题型或离开练耳取消旧题的后续声音。
- 乐理图解移除重复的悬浮试听提示，保留图解及音符试听。
- 琴头 SVG 在不同宽高比下填充实际容器，旋钮松手和键盘调节使用短缓动，拖动保持即时响应；窄屏弦钮内收，降低音名气泡和旋钮重叠。
- PWA 更新检查兼容极快完成的 Service Worker，并延长大资源包更新检查等待时间；缓存清理使用显式同作用域标记，避免留下旧版本或误删相邻副本。
- 节拍器播放区增加计拍方式入口，已保存的节奏编排可以直接播放、载入并设为节拍器作品；小节数支持 1–8，小屏分页改为带文字的轨道与时间分组。
- 和弦探索指板使用可用宽度，默认保持 12 品并提供 85%–135% 缩放；练耳高级训练收进“更多练耳”，视唱和练耳操作按钮统一到可触控尺寸。
- 调音器琴头改为三列视觉组件，左侧对应 4/5/6 弦，右侧对应 3/2/1 弦；弦按钮缩小并与旋钮行对齐，检测和显示选项收回琴头标题区。
- 节拍器增加首拍叠加、强弱规律、重音移位三种重音方案，并加入可视化节拍器、分拍灯条、冲击脉冲、前进节奏块、震动开关和渐速停靠条。
- 增加全局学习小贴士，覆盖半音、全音、Swing、重音移位、和弦、音程、五度圈、五声音阶、布鲁斯音阶和特殊调弦，支持随机换一条和跳转到对应工具。

## 文件与交付

- index.html：基础 DOM 与核心逻辑。
- app-final.css / app-final.js：最终覆盖层，修改前必须定位最后生效定义。
- drum-workshop.js：八轨编排与鼓组；ear-progressions.js：和弦进行与练耳播放设置。
- sight-library-v2.js / special-tunings-v1.js：离线曲库和特殊调弦。
- assets / icons / licenses：本地素材、图标、许可与来源证据；`licenses/learning-sources.json` 登记学习内容和 Web 能力来源。
- sw.js / version.json / release-assets.json：版本化、校验后的原子离线缓存。
- Music-Toolbox-Ultra-v13.5.21-Standalone.html：生成的离线单文件，不手工编辑。
- tools：构建与 QA；package.json / package-lock.json 只声明 QA 开发依赖。

版本目录不含 node_modules、开发试听页、测试浏览器资料或旧单文件。
正式部署上传本目录内容，包括隐藏的 .github；不要上传父目录 development。
Cloudflare 必须保留 _redirects 中的 /index.html / 200，防止缓存带重定向的首页。

## 构建与验证

建议 Node.js 24，与 CI 一致：

```bash
npm ci --ignore-scripts
node tools/build_standalone.mjs
node tools/build_release.mjs
node tools/build_release.mjs --check
node tools/qa_final.mjs
```

本工作区复用外置依赖时，最后一步为：
`node --import ../../development/qa-dependencies.mjs tools/qa_final.mjs`。

验证结果由 release-validation.json 生成。资源清单记录文件大小和 SHA-256，不手工伪造。
额外浏览器脚本为父工作区 development/qa-13.5.21-ui.mjs 与 development/qa-13.5.21-pwa.mjs，均使用临时 Chromium 配置，不读取用户浏览器数据。

## 发布与离线

GitHub Pages 在仓库 Settings → Pages 选择 GitHub Actions；提交 main/master 后工作流安装锁定 QA 依赖、完整验证，再发布预构建文件。
Cloudflare 使用该版本独立部署目录；此前 Direct Upload 项目不会自动随 GitHub 更新。

PWA 首次联网完整缓存 147 项正式资源以及清单；新资源全部验证成功才淘汰旧缓存。安装入口按平台提供原生安装或指引。
“重置缓存”先探测网络，再清理当前工具箱范围缓存、注册和设置；不能代替浏览器清理系统权限或 HTTP 缓存。
单文件本地可用，但不会自动更新，也不保证 file:// 下获得麦克风权限；调音与录音推荐 HTTPS 或 localhost。
