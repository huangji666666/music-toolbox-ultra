# 音乐工具箱 Ultra

最终发布版：`v13.5.8`  
开发者：黄鸡（BY 黄鸡）

本目录是同一套最终代码生成的两个交付形态：

- `index.html` 与配套文件：GitHub Pages / PWA 正式版。
- `Music-Toolbox-Ultra-v13.5.8-Standalone.html`：手机本地直接打开的单文件版，用于快速检查；不提供 Service Worker 自动更新。

目录中不包含任何旧测试版文件。

## GitHub Actions 发布

1. 解压最终压缩包。
2. 把最外层项目目录里的全部内容上传到 GitHub 仓库根目录，包括隐藏目录 `.github`。
3. 在 GitHub 仓库中打开 `Settings → Pages`，将 `Source` 设为 `GitHub Actions`。
4. 向 `main` 或 `master` 分支提交后，工作流会安装锁定的 QA 依赖，运行完整 QA，并校验全部离线素材的文件大小和 SHA-256，再整体发布。
5. Actions 页面显示绿色成功后，再刷新正式网址。

仓库名和 Pages 子路径可以改变。所有站内资源均使用相对路径，不依赖固定的 GitHub 用户名或固定项目名称。

## 离线与更新机制

- 第一次从 HTTPS 正式网址进入时，PWA 会把页面、脚本、样式、26 个节拍器重拍音色、制音、图标、视唱曲库及赞助/联系图片完整缓存到设备。
- 新版本必须先把资源清单里的全部文件下载并校验成功，才会替换旧缓存。某个文件缺失时只删除本次临时缓存，保留设备里的完整旧版。
- 进入页的“检查失败”会显示具体缺失路径；不会阻止使用当前完整版本。
- 进入页可按浏览器能力一键“添加到桌面”；iPhone 等不支持一键安装的平台会显示操作指引。
- 进入页“重置缓存”会在确认后注销 Service Worker、删除 CacheStorage、本地设置和自定义数据，并带缓存破坏参数重新联网载入。
- 直接打开本地单文件不会检查云端更新；正式 PWA 才会跟随已部署网页更新。

## iPhone 与麦克风

应用启动时只初始化媒体播放，不会预先占用麦克风。进入调音器或开始录音时才申请麦克风，离开后释放并尝试恢复播放路由。设置页提供“标准原声、iPhone 延音增强、系统语音增强”三种采集方式；iPhone 长音只闪音头时优先试用“iPhone 延音增强”。iOS 浏览器在麦克风开启期间可能仍由系统显示录音音量界面，这是 Safari / WebKit 的系统行为。

## 发布前本地校验

需要 Node.js 18 或更高版本：

```bash
npm ci --ignore-scripts
node tools/build_standalone.mjs
node tools/build_release.mjs
node tools/build_release.mjs --check
node tools/qa_final.mjs
```

全部通过后，`release-assets.json` 才与当前项目一致。以后改动任何正式资源，都必须重新运行上述构建与校验。

## 本轮关键修复

- PWA 改为完整资源清单与原子缓存，修复网页端重拍音色、赞助二维码和离线素材缺失。
- 默认重拍 `02 · 木块强击·圆润` 在第一拍调度前完成加载；普通拍继续使用电子 Click。
- 音频播放初始化与麦克风采集分离，改善 iPhone 音频路由和调音器持续识别。
- 调音器加入自适应噪声门、稳定帧与短时显示保持，不再只闪第一下音头。
- iPhone 顶部安全区统一应用到普通、紧凑和矮屏布局，并为独立安装模式预留 60px 最小安全区。
- 视唱自动布局为手机每行 1 小节、平板每行 2 小节，并保留横向、单行、双行和网格选择。
- 视唱“上一题／上一句／下一句／下一题”移出谱窗裁剪层，iPhone 与 Android 均保留完整一行。
- 渐速训练默认进入精简版；精简版 DOM 不再生成“从／到 BPM、每次变化、预计时长”等高级字段。
- 和弦根音气泡以自身中心精确对齐十二半音刻度，首尾 C 不再向内偏移。
